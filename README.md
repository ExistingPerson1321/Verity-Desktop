# Verity-Desktop
Verity doesn't just exist in Minecraft, he lives on your desktop now! Interact with all the features in the Verity Desktop application! A "functional" emotion engine, file locator/executor, desktop analysis and a media player, he's all you'll ever need on your Windows PC!

Verity is supported on Windows 7 and up!

Features list/usage:
. Media Player - Ask "play SONGNAME by ARTIST", uses Youtube to play music
. Emotion engine - Triggered by specific words, with sprites to match emotion (Trigger words: Happy, Down, Angry)
. Desktop Analysis - Click the Camera button next to the Play button in his input box to analyse the desktop, if you want to specify an instruction, you can type text and click the Camera button instead of the Play button
. File Locator - Say "locate" or "find" filename.extension
. File Executor - Say "open" or "run" filename.extension (not just exe files!)
. Bonus Feature: NETWORK CHATTING - Verity Instances on the same network can talk to each other and the user can "ping" all instances a question or instruction (Say "ping everyone QUESTION")
